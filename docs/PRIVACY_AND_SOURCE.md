# Privacy and Source

## What this repository is

A portfolio showcase for a desktop game project. It describes the engineering of 2D Mario; it is not a source distribution.

## What is published

- Written descriptions of architecture, design decisions and trade-offs
- An original conceptual diagram
- Real screenshots and a short clip from a local build
- This documentation

## What is intentionally not published

- Source code, level data and build scripts
- Game artwork, audio and fonts
- Internal working notes, scripts and logs

## Data

The game is single-player and offline. It collects no personal data, has no accounts and writes no save files. Screenshots show only in-game content produced by a scripted run.

## Third-party assets

The game uses artwork, a pixel font and audio that were not created for this showcase and may come from third parties. Their licences are not confirmed here, so the assets are not redistributed. Appearances in screenshots are for demonstration only. See [RIGHTS.md](../RIGHTS.md).
